# 对话迁移记录

## 需求

用户希望实现一个本地 MVP：

- 自动采集某位 X/Twitter KOL 最近最多 500 篇公开历史文章/posts。
- 存入 SQLite。
- 基于历史内容生成该 KOL 的写作风格画像。
- 后续用户输入文章大意和主旨，系统按照该风格画像生成原创文章。

## 实现原则

- 使用 X 官方 API，避免未授权网页爬虫。
- 默认采集最近 500 条以内，按分页最多每次 100 条。
- 可排除 replies 和 retweets，优先分析原创内容。
- 风格学习采用 LLM 生成“风格画像”，不是直接 fine-tune。
- 生成文章时只借鉴结构、节奏、论证方式，不冒充原作者，不复制原句。

## MVP 模块

- 样本通过逐篇录入或批量导入进入数据库。
- `app.db`: SQLite 建表、保存和查询。
- `app.style`: 风格画像生成和文章生成逻辑。
- `app.llm`: OpenAI Responses API 封装。
- `app.main`: FastAPI 接口。
- `app.cli`: 本地命令行入口。
